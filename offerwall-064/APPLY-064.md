**JS 만 · 0.6.3 tgz 와 비교해 멤버 77개 중 7개(README · dist/OfferwallScreen.js·.d.ts · dist/comboEntry.js · src/OfferwallScreen.ts · src/comboEntry.ts · package.json)만 다르고 네이티브 13개 멤버는 바이트까지 같다.** 판 · sha256 · integrity 는 `INTEGRITY-0.6.4.txt` (파일에서 계산한 값 — 락은 `npm install` 이 만든 값을 쓰고 손으로 옮기지 말 것). 0.6.3 의 나머지 동작은 그대로. 에그머니 1.1.8 줄(vendor 0.6.3) 교체용.

## 1) 「찬스를 불러오지 못했어요」 (A32, 앱보조4 요청)
`ClassicScreen`(애드팝콘 월)의 20초 오류 타이머가 ① `usn` 이 null 인 동안(앱의 `open()` 이 끝나기 전) ② 찬스2 가 올라와 월이 숨겨진 동안에도 돌았다.
- 타이머는 **`usn` 이 있고 + 월이 보일 때(`hidden=false`) + 아직 로드/오류가 아닐 때만** 돈다. 멈췄다 다시 켜지면(회원이 오거나 다시 보이면) **처음부터 20초**.
- 숨겼다 다시 보이는 순간 오류 상태면 **자동으로 한 번 재시도**(`attempt`+1, `onRetry()` 는 부르지 않음). 오류당 한 번: 자동 재시도나 「다시 시도」 단추를 한 번 쓰면 이후 실패는 단추로만, 로드에 성공하거나 `usn` 이 바뀌면 다시 자격이 생긴다. 숨김 중 네이티브가 `onError` 를 보낸 경우도 같다.
- 로드가 끝난 월은 숨겼다 돌아와도 다시 불러오지 않는다(0.5.0 동작). 탭 UI · 네이티브 · 공개 props · 표식 상수 그대로(새로 보이는 것: `wallTimerShouldRun` · `wallAutoRetryOnShow` · `CLASSIC_WALL_TIMEOUT_MS`).

## 2) 칩이 탭 줄을 덮음 (A32 2p1-r2 캡처, 앱보조4)
`OfferwallScreen` 이 자기 effect 에서 탭 줄 높이를 알리는데, 앱에서 다음 형제로 붙은 `ComboEntry` 의 구독 effect 보다 먼저 돌아 첫 알림(45)을 놓쳤고(렌더 때 0 을 읽음), 이어서 실측 45 가 폴백 45 와 같아 다시 알림도 없었다 → 칩 top = 6 + 0. 이제 `ComboEntry` 는 **구독 직후 현재 값을 읽어 맞춘다** — 탭 inset 과, 같은 모양인 고른 탭(`getChanceTab`)·월 로드 신호(`isWallLoaded`)도.
